# Park & Revisit — ADHD Budgeting App

A number-free, shame-free app that helps adults with ADHD pause before a
non-essential purchase, reflect, and then decide — separating the buying
urge from the decision.

**Status:** Product specifications complete. Build starts Week 3+. No code yet.

## The idea (MVP)
Save an item → wait (with a brief reflection) → decide: buy / let go / still deciding.
It serves the *hesitation moment* ("should I think about this more?"), giving
the user control instead of policing their spending.
